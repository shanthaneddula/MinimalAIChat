# Glossary of Terms

This document provides definitions of key terms and concepts used in the MinimalAIChat project to ensure consistent understanding among developers, contributors, and users.

## A

### API Key
A unique identifier used to authenticate requests to the OpenAI API or other AI service providers.

### App Transport Security (ATS)
An Apple security feature that ensures apps connect only to web services using secure HTTPS connections.

### App Store Connect
Apple's platform for managing app submission, updates, and analytics for App Store distribution.

## B

### Background Process
A system component that runs independently of the user interface, such as the hotkey monitoring service in MinimalAIChat.

### Build Configuration
A set of compiler and linker settings that define how the application is built (Debug, Release, etc.).

## C

### Certificate Pinning
A security technique that validates server SSL certificates against a predefined set of trusted certificates to prevent man-in-the-middle attacks.

### Chat Context
The historical conversation data maintained to provide continuity in AI interactions across user sessions.

### Chat Model
Refers to the specific AI language model used for generating responses (e.g., GPT-4, Claude).

### Completion
A response generated by an AI model based on a given prompt.

## D

### Dark Mode
A user interface display mode using a darker color palette to reduce eye strain in low-light environments.

### DMG (Disk Image)
A macOS disk image format used to distribute applications outside the App Store.

### Direct Distribution
Distribution of the application outside the Mac App Store, typically through a website download.

## E

### Entitlements
Special permissions granted to macOS applications that allow access to system features like keychain storage, network capabilities, etc.

### Event Monitor
A system that captures global keyboard or mouse events, used in MinimalAIChat to detect the activation hotkey.

## F

### Fastlane
An open-source tool used to automate the build and release process for macOS and iOS applications.

### Focus State
The current user focus context within the application, determining which UI elements are active.

## H

### Hardened Runtime
A macOS security feature that adds protections to prevent code injection and restrict runtime access to system resources.

### Hotkey
A keyboard shortcut used to invoke MinimalAIChat from any application (e.g., ⌘+⇧+Space).

### HotkeyManager
The core system component responsible for registering, detecting, and responding to the global hotkey combination.

## K

### KeyCombo
A data structure representing a keyboard shortcut combination, including modifier keys (⌘, ⇧, ⌥, ⌃) and character keys.

### Keychain
Apple's secure storage system for sensitive information such as API keys and credentials.

## L

### LaunchAgent
A macOS system feature that allows applications to run automatically at login or in the background.

### Light Mode
The default user interface display mode using a lighter color palette.

## M

### Memory Pressure
The state of the system's memory resources, which MinimalAIChat monitors to optimize resource usage.

### MemoryPressureObserver
A component that monitors system memory availability and responds to low-memory conditions.

## N

### Notarization
Apple's security process that verifies macOS applications distributed outside the App Store are free of malicious content.

## O

### Offline Mode
A feature allowing users to view previous conversations when no internet connection is available.

## P

### Preferences
User-configurable settings for MinimalAIChat, such as appearance, hotkey, and behavior options.

### Privacy Consent
User agreement to data collection and processing terms, required for GDPR and other privacy regulations.

## R

### Receipt Validation
The process of verifying the authenticity of App Store purchase receipts for subscription validation.

### Release Candidate (RC)
A build that is potentially the final version before public release, pending testing results.

## S

### Sandbox
A security mechanism that restricts an application's access to system resources and user data.

### Semantic Versioning
A versioning scheme in the format of MAJOR.MINOR.PATCH used to communicate the nature of changes in each release.

### Sparkle
An open-source framework used to implement automatic updates for macOS applications distributed outside the App Store.

### Spotlight Integration
The capability for MinimalAIChat conversations to be indexed and searchable via macOS Spotlight.

### Status Bar Item
The icon displayed in the macOS menu bar that provides access to MinimalAIChat functionality.

### StoreKit
Apple's framework for in-app purchases and subscriptions.

### Subscription Model
The business model where users pay a recurring fee to access premium features or usage tiers.

## T

### TestFlight
Apple's platform for beta testing iOS and macOS applications before release.

### Thread-Safe
Code that can be safely executed by multiple threads concurrently without causing data corruption or race conditions.

## U

### Universal Links
A technology that allows apps to handle links to specific content or features, used for deep linking in MinimalAIChat.

### User Agent
A string identifying the application in web requests, containing information about the application and system version.

## W

### WebKit
Apple's framework for rendering web content, used by MinimalAIChat to display the chat interface.

### WebView
The UI component that uses WebKit to render web content within the native application.

### WebViewModel
The data model that manages the state and behavior of the WebView component.

## X

### XCTest
Apple's testing framework used for unit and UI testing of MinimalAIChat.
